Automated MT5 Backtesting
Description: These scripts automate the MetaTrader 5 backtesting process. tester3.py is the debugged and improved version of tester2.py (it includes fixes for Unicode errors, pipe characters | in EA names, and corrected M5 timeframe mappings). It scans a specified folder for .ex5 files, launches the MT5 terminal in the background to test them against your defined parameters, and saves the extracted performance metrics into a CSV and JSON file.

How to Use:

Open tester2.py in your code editor.

Scroll to the bottom (if __name__ == "__main__": block).

Update the configuration variables to match your environment:

MT_TERMINAL_PATH: The path to your terminal64.exe.

EA_FOLDER: The directory containing your .ex5 files.

SYMBOLS, TIMEFRAMES, START_DATE, END_DATE: Your desired backtest parameters.

Open your terminal or command prompt and run:

Bash
python tester2.py


2. multiple_html_analyzer.py - MT5 Report Consolidator
Description: MetaTrader 5 generates a separate HTML report for every single backtest. This script safely reads all those individual HTML files (handling MT5's native UTF-16 encoding), extracts key metrics (Net Profit, Profit Factor, Drawdown, etc.) using Regex, and compiles them into a single, clean HTML table for easy comparison.

How to Use:

Place multiple_html_analyzer.py in the exact same directory where your individual MT5 HTML backtest reports are saved.

Open your terminal in that directory and run:

Bash
python multiple_html_analyzer.py
Open the newly generated SONUC_TABLOSU.html file in your web browser to view the consolidated data.

3. sonucSiralama.py - Quick Results Sorter
Description: A quick command-line filtering tool. It parses the consolidated SONUC_TABLOSU.html file using BeautifulSoup and categorizes your tested EAs into three distinct lists: Profitable (Net Profit > 0), Loss-Making (Net Profit < 0), and Inactive (0 trades taken).

How to Use:

Ensure the SONUC_TABLOSU.html file (generated by the previous script) is in the same folder.

Run the script via your terminal:

Bash
python sonucSiralama.py
Review the categorized summary printed directly to your console.
